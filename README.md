# 🔐 Caesar Cipher — Text Encryption & Decryption

## 📌 About the Project
Caesar Cipher is a simple text encryption and decryption program built using Python. It uses a classical substitution cipher technique in which each letter is shifted by a specified number of positions in the alphabet.

This project helps beginners understand Python functions, loops, conditional statements, and string manipulation.

## ✨ Features
- 🔒 Encrypt messages using a shift value
- 🔓 Decrypt encrypted messages
- 🔁 Supports repeated encryption and decryption
- 🔤 Preserves spaces and special characters
- 🔄 Wraps around the alphabet when shifting letters
- 🖥️ Simple command-line interface

## 🛠️ Technologies Used
- Python 3
- Functions
- Loops and conditional statements
- Strings and lists
- User input and output



## 🚀 How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the command:

```bash
python main.py
```

## 🎮 How to Use

1. Choose whether to **encode** or **decode** a message.
2. Enter the message you want to process.
3. Enter the shift number.
4. View the encrypted or decrypted result.
5. Choose whether to continue or exit, if prompted.

## 💡 Example

**Original message:** `hello`

**Shift value:** `3`

**Encrypted message:** `khoor`

**Decrypted message:** `hello`
